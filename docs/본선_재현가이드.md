# 동해시 AI 잇다: 본선 재현 가이드

## ★ 11/19 개편: 서비스 한 줄 = "사진 한 장 올리면 동해 업체들이 견적을 보내드려요"
지원사업·법·업체를 한 화면에 늘어놓던 구조를 버리고 **견적 받기** 하나로 정리했습니다.
1. 시민 `/`: 사진·증상 → AI가 견적 요청서 작성 → (해당되면) 지원금 먼저 알림 → 이름·연락처 넣고 동해 업체 5곳 안팎에 요청
2. 시민 `/r/[링크]`: 도착한 견적을 금액·면허·실적·방문 일정으로 비교 → 한 곳 선택 (그때만 연락처가 그 업체에 전달). 미가입 업체는 전화 목록으로 안내. 지원금·계약 전 법 체크 함께 표시
3. 업체 `/pro`: 들어온 요청(사진·AI 정리) 보고 견적(금액 범위·방문일·기간·메시지) 보내기 → 선택되면 시민 연락처 확인
4. 주무관 `/admin`: 창구 대리 접수(접수 후 견적 확인 링크를 문자로), 현황판(공정별·동별 요청, 견적 응답률, 업체 쏠림)
- DB: `requests`, `quotes` 테이블 + 함수 `create_request`, `get_request`, `choose_quote`, `pro_requests`, `submit_quote` (마이그레이션 `v3_quote_requests`). 시민은 비밀 링크 토큰으로만 자기 요청을 봄
- 검증(11/19): 요청 생성 → 업체에 연락처 숨김 → 견적 → 시민 선택 → 업체에 연락처 공개 → 선택 후 재견적 차단까지 DB에서 통과
- 시연 순서: 시민 화면에서 요청 → 업체 화면(테스트 로그인)에서 견적 → 시민 링크 화면에서 비교·선택 → 업체 화면에 연락처 뜨는 것 → 주무관 현황판

사전 기술검증(2026-11-17)에서 실제로 만들고 배포한 순서 그대로입니다. 본선(11/20~21)에서 같은 과정을 다시 밟으면 됩니다.

본선에서 새로 만들 경우, 위 연결이 그대로라면 승인 단계 없이 바로 진행됩니다.

## 1. 구조

```
시민(/)        ─┐
주무관(/admin)  ─┼─ Next.js (Vercel) ─┬─ /api/diagnose → Gemini (판별) ─ 실패 시 키워드 판별
시공업체(/pro)  ─┘                     ├─ /api/match    → Supabase (규칙으로 지원사업·업체·법 안내 선택)
                                       ├─ /api/inquiry  → Supabase inquiries
                                       ├─ /api/preview  → Gemini 이미지 (실패 시 색 바꾸기)
                                       └─ /api/seed     → 일회용 데이터 적재
```

원칙은 하나입니다. AI는 "어떤 공사인지" 판별하고 쉬운 말로 설명만 합니다. 지원사업·업체·법 안내는 DB 규칙으로만 고릅니다. 그래서 AI가 업체나 지원금을 지어낼 수 없습니다.

## 2. 순서

### ① Supabase 프로젝트
1. 새 프로젝트를 서울 리전(ap-northeast-2)에 만듭니다.
2. SQL Editor에서 `supabase/01_schema.sql`을 실행합니다. 테이블 9개, RLS, 업체 수정 제한 트리거가 만들어집니다.
3. `supabase/02_seed_functions.sql`에서 `<SEED_TOKEN>`을 임의의 긴 문자열로 바꾸고 실행합니다.

### ② 데이터 파일 (이미 저장소 `data/`에 있음)
| 파일 | 내용 | 만드는 법 |
|---|---|---|
| businesses.json | 업체 1,967곳 (시민 노출 475곳 + 시연 업체 1곳) | `python3 scripts/build_businesses.py 동해시_사업자_통합DB.xlsx businesses.json` |
| programs.json | 지원사업 46개 + 대상(audience)·조건(requires) 태그 | `python3 scripts/build_programs.py donghae_support_programs_v3_1.json` |
| work_types.json | 공정 매핑표 14개 (시민 표현 → 공정 → 업체 분류·지원사업 태그) | 직접 작성 |
| legal_notes.json | 공정별 법·안전 안내 14개 (근거 법령 포함) | 직접 작성 |

업체 정리 규칙:
- 시민 화면에 노출하는 업체: 집수리 분야 10개 분류 중 (신뢰도 ★★ 이상 또는 전화+주소 보유)이고 영업정지가 아닌 곳.
- 실적이 0건이고 ★★★가 아닌 업체는 "신규"로 표시해 고르게 노출합니다.
- 대표자명은 빼고, 사업자번호는 비공개 테이블(business_private)에만 둡니다. 주무관만 볼 수 있습니다.
- 가족 업체 2곳(방도건설주식회사, 이원상사)은 이해충돌 방지를 위해 제외합니다.

### ③ Vercel
1. 저장소를 import합니다. Claude는 `create_git_project`를 씁니다.
2. 환경변수를 넣습니다.
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`: 공개 키라 노출돼도 됩니다. RLS가 막습니다.
   - `SEED_TOKEN`: ①의 3에서 정한 값.
   - `GEMINI_API_KEY`: 사용자가 Vercel 화면에서 직접 넣습니다.
   - `GEMINI_MODEL`, `GEMINI_IMAGE_MODEL`: 비워도 됩니다. 코드가 후보 모델을 순서대로 시도합니다(판별 gemini-3.5-flash → 2.5-flash, 이미지 gemini-3.1-flash-image → 2.5-flash-image).
   - `DEMO_MODE`: `1`이면 AI 없이 키워드 판별만 합니다. 와이파이가 불안할 때 씁니다.
3. main에 push하면 배포됩니다.

### ④ 데이터 적재
1. `https://<배포주소>/api/seed?token=<SEED_TOKEN>`을 엽니다. 정상이면 `{"ok":true,"out":{"work_types":14,"programs":46,"businesses":1967,"business_private":1377,"legal_notes":14}}`가 나옵니다.
2. `02_seed_functions.sql` 맨 아래 revoke 두 줄을 실행해 적재 함수를 잠급니다.
3. `supabase/03_demo_accounts.sql`에서 비밀번호 자리를 채워 실행합니다. 주무관·시공업체 시연 계정과 시연용 가상 업체가 만들어집니다.

### ④-2 2차 보강 때 추가한 DB 변경 (Supabase 마이그레이션 `v2_logging_exposure_demo`)
- `consultations.floors` 열, `log_consultation(jsonb)` 함수(공정을 고쳐도 상담 1건으로 집계), `my_exposure()` 함수(업체가 자기 소개 횟수 확인)
- 문의는 공개된 업체에만 넣을 수 있게 정책 강화
- 데이터를 고쳤을 때: 적재 함수 권한을 잠깐 열고(`grant execute ... to anon`) `/api/seed`를 다시 부른 뒤 다시 잠그기

## 3. 화면별 시연 포인트

| 화면 | 보여줄 것 | 한 줄 메시지 |
|---|---|---|
| 시민 `/` | 사진 → 판별 → 지원사업 → 법 안내 → 업체 → 문의 → 미리보기 | 사진 한 장이면 어디에 맡기고 뭘 지원받는지 끝 |
| 주무관 `/admin` 창구 모드 | 어르신 대신 입력 → 문자 요약 복사 | 행정복지센터 창구에서 바로 쓰는 보조 도구 |
| 주무관 `/admin` 현황판 | 공정별·동별 수요, 신규 업체 노출 비율 | 수요 데이터로 예산 배분, 쏠림 없는지 수치로 확인 |
| 시공업체 `/pro` | 문의함, 내 공정 법·안전 기준, 업체 지원사업 | 정보 입력해도 순위가 안 올라감, 공정한 노출 |

## 4. 사고 대비
- Gemini가 느리거나 실패하면 자동으로 키워드 판별로 넘어갑니다. 화면에 "키워드 판별"로 표시됩니다.
- AI 이미지가 실패하면 "색 바꾸기" 미리보기를 씁니다. 브라우저에서 바로 돌아가 인터넷이 없어도 됩니다.
- 시연 전에 `DEMO_MODE=1`로 바꾸면 AI 호출이 완전히 꺼집니다. Vercel에서 환경변수를 바꾼 뒤 재배포해야 적용됩니다.
- API 사용량 제한: IP당 판별 20회/분, 이미지 5회/10분, 문의 10회/10분.

## 5. 알려진 한계 (질문 대비)
- 업체 주소에 동 정보가 거의 없습니다(도로명주소). 동별 통계는 시민이 입력한 동 기준입니다.
- 법 안내는 요약입니다. 개별 사안은 건축과 등 담당 부서 확인 문구를 함께 띄웁니다.
- 지원사업 금액·기간은 매년 바뀝니다. 주무관 화면에서 일정을 고치거나 끌 수 있습니다.
- 네이버 지도 데이터는 수집이 막혀 반영하지 못했습니다.
